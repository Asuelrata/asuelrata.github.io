# Asuelrata github.io

Bienvenidos a este pequeño proyecto personal que no tiene objetivo de llegar demasiado lejos. Aquí subiré algunas """webapps""" personales y algun programa de interés general, siempre suponiendo que dedique el tiempo y las ganas a hacerlo

Por hablar un poco de los proyectos que subo en el commit inicial (ya veremos si termino actualizando este README...)

## Eclipsador

Muy simple, como seguimos chinados #1 porque nuestro equipo al final se llama Ollauri on Tour tras una encuesta interna de dudoso rigor y #2 que la cuenta de Instagram oficial es un mierdón, decidimos hacer nuestra propia cuenta para llevar la actualidad del equipo: **eclipseo_on_tour**

Esta pequeña aplicación nos ayuda a generar la imagen de convocatoria que subimos a las historias de IG. Actualmente falta incluir el diseño de nuestra segunda equipación

## Bingo Pokeñol

Aprovechando que he hecho la funcionalidad de **Eclipsador** y el funcionamiento es prácticamente el mismo, he hecho esta pequeña aplicación que también usa un canvas para montar imágenes y así facilitarnos actualizar el bingo de discord

Este mini programa ha presentado el reto de implementar cookies para facilitar el uso continuado durante el año, y manipular cookies en javascript plano es un mierdón mesopotámico. Al final con contains, replaces y splits se ha conseguido un programa que a priori funciona y subo para testeo
